# CineGroup 🎬

Plataforma web interativa desenvolvida para integração de redes de amigos com foco na descoberta, organização e compartilhamento colaborativo de produções cinematográficas.

---

## 🚀 Sobre o Projeto
O **CineGroup** funciona como um site onde os usuários podem gerenciar listas de filmes, acompanhar o histórico de assistidos e pendentes, além de entrar em grupos de amigos e trocar avaliações e experiências.

Trata-se de um trabalho prático desenvolvido para a disciplina de **Desenvolvimento Web Front-End** do curso de Ciência da Computação da Universidade FUMEC.
